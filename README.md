# 📊 Генератор B2B-карточек товаров (MVP)

Прототип сервиса для автоматизации контента интернет-магазина измерительных приборов (манометров, датчиков давления). Скрипт принимает технические характеристики в формате JSON, отправляет их в LLM и возвращает готовую структуру для карточки товара.

🌐 **[Открыть работающий прототип (GitHub Pages)](https://ВАШ_НИК.github.io/НАЗВАНИЕ_РЕПОЗИТОРИЯ/)**

## ⚙️ Возможности
*   **Интеграция с LLM:** Поддержка OpenAI-совместимых API (OpenAI, OpenRouter, Groq и др.) и Anthropic.
*   **Генерация контента:** Создает SEO-заголовок (до 70 симв.), SEO-описание (800–1200 симв.), список ключевых характеристик, поисковые запросы и коммерческий блок для менеджера.
*   **Защита от галлюцинаций:** Жесткий системный промпт и встроенная пост-валидация, которая сверяет сгенерированные характеристики с исходными данными и подсвечивает несоответствия.
*   **Удобный интерфейс:** Таймер выполнения, обработка ошибок API, возможность загрузить `.json` файл, скопировать или скачать результат.

## 🛠 Техническая реализация
*   **Стек:** Чистый JavaScript (Vanilla JS), HTML5, CSS3. Без сборщиков и тяжелых фреймворков.
*   **Архитектура:** Single Page Application (SPA), полностью работающее на стороне клиента. Весь код умещается в один файл `index.html`.
*   **Безопасность:** API-ключи не хранятся в коде. Пользователь вводит ключ вручную, он сохраняется в локальном хранилище браузера (`localStorage`) и отправляется напрямую в API провайдера.

## 🚀 Как запустить локально
Так как проект состоит из одного статичного файла, просто откройте `index.html` в любом современном браузере. Никакие серверы или установка зависимостей не требуются.
